# MOP 2.0 v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make first-MOP months resolve more distinctly, preserve a guided MOP chapter after first purchase, and add a contextual notable-month fast path.

**Architecture:** Extend the existing monthly-intent and life-summary pipeline instead of introducing a new campaign engine. Apply small safe ownership actions before advancing, carry intent context through month resolution, and let the dashboard skip month-by-month until a notable state change is detected.

**Tech Stack:** React 19, TypeScript, Zustand, Vitest, Vite
